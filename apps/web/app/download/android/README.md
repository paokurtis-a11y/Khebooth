# Canal Android KHE Booth

Le chemin public `/download/android` présente le canal officiel Android.
Le chemin `/download/android/latest` redirige vers l’asset `KHE-Booth-Android-debug.apk` de la release GitHub stable `android-latest`.

La CI mobile remplace automatiquement cet asset lors d’un push sur `main` qui déclenche le workflow mobile.
